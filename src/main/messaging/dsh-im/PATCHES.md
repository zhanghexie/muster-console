# dsh-im provenance and Muster changes

Source is [xmanrui/dsh-im 5.10.0](https://github.com/xmanrui/dsh-im/tree/fc2ceab217309f8973afa03c58cdd8ff3e900130), commit `fc2ceab217309f8973afa03c58cdd8ff3e900130`. The original import was drawn from upstream `src/`, `plugin-src/host/`, `plugin-src/client/`, `plugin-src/management-rpc.mjs`, `locale/`, `LICENSE` and `THIRD_PARTY_NOTICES.md`. Copyright and third-party terms remain in the latter two files.

- `channel-runtime.mjs` starts the platform transports from Muster’s `MessagingHost`. Management uses an in-process handler registry. The account page is part of Channels, and pairing is scoped to a Channel source. The source tree drops the upstream plugin entry points, updater, independent IM session bridges, and old settings pages. Existing account paths and credential references remain readable.
- Unified Channel uses the authenticated transport to discover and receive a source. `logical-delivery.mjs` maps the stored source and native message reference to the relevant sender, chat, topic, or thread. Ordinary mail uses its original subject and reply references. WeChat reuses the recipient's stored context token, and source replies and proactive sends require current host authorization.
- The host claims physical Feishu application and standard IMAP mailbox identities before their consumers start. The pinned Lark SDK patch tracks pending, live, and reconnect sockets through close. IMAP checks ownership before probing credentials in a new bind and again before polling. Runtime shutdown releases its claim after the connection has closed, and retains ownership if shutdown cannot be confirmed.
- Platform adapters forward authenticated sender, destination and message identities into the unified Channel service. Muster owns desktop pairing and routes accepted input to its current scheduler session or an existing work session. Replies use the invoking transport and destination, including the originating iLink context token. AI Office keeps its task connector and uses a dedicated, injected Muster session client.
- Email continues to read configured mailboxes. In unified Channel mode messages can arrive in an authorized inbox, and remote authorizations are scoped to supported chat providers. Generic `From` and `Authentication-Results` headers remain mail metadata.
- The platform adapters take a Channel message receiver. `src/channels/shared/bot-workspace-store.mjs` scopes receives and replies to the current account incarnation. `adapters/host/channels/office/production.mjs` uses the configured device ID to scope Office jobs.
- `adapters/host/channels/shared/access-policy-production.mjs` starts direct and group routes with allowlists. Telegram and WhatsApp can seed explicitly entered direct users. Binding the transport does not grant an owner bypass or command privileges.
- QQ QR setup loads the separately installed official connector on demand. Install `@tencent-connect/qqbot-connector@1.2.0` into `optional-connectors/qq/node_modules` below the host's messaging data directory. Upstream reports this package as `UNLICENSED`. Its code is excluded from the Muster dependency tree. Manual AppID and AppSecret setup uses the bundled application's `@tencent-connect/qqbot-nodejs` dependency.
- `adapters/host/channels/shared/startup.mjs` registers ownership before publishing delivery or the final request handler and allows disposal to be retried. The shared TokenBot controller retains failed handles and runs its cleanup alongside the startup supervisor. `src/channels/shared/muster-socket-close.mjs` waits for Slack and Discord socket close. Runtime stop methods for Telegram, QQ, WhatsApp, Feishu and Email await the promises for their work and event queues.
- `scripts/build-messaging.mjs` builds ESM chunks, applies upstream's reviewed Lark handshake fixes and embeds the installed Lark SDK version. The application ships `out/main/messaging/dsh-im-attribution.txt` with the upstream license and notices plus the actual version list resolved from Muster's package lock. For example the installed Undici is 7.30.1 and protobufjs is 7.6.6. Matrix's external Olm package supplies its WASM.
- iMessage uses macOS Messages, Full Disk Access for its read-only mailbox scan, and Messages automation permission to send. Outgoing messages use the Muster marker. The receive path recognizes both the new marker and the original DSH marker to filter echoes. The product disables this channel on Windows and Linux. WhatsApp uses the upstream Baileys linked-device protocol. The Agent Mail transport uses the separately installed `agently-cli`; ordinary email uses the application's IMAP and SMTP dependencies.

- `src/channels/shared/semantic/artifact.mjs` adds a Muster-only byte snapshot factory. The host supplies bounded bytes after checking the exact turn file evidence and workspace path; upstream provider materialization and cleanup use the same module-owned artifact registry. Renderer styles load the original per-channel CSS inside the Muster settings scope, with host motion tokens and platform-specific permission instructions.
