先统一阅读基底

两边都使用主面背景，让标题、段落和正文层级来承担结构。代码块与图片仍可以留在自己的局部表面上，因为它们需要不同的阅读和操作方式。

  1. 虚拟屏中缝保留一条很浅的线，拖动时再增强。
  2. 列表选中不必像输入框一样浮起；它只要清楚标明当前位置。
  3. 面板控制降低亮度，把工作区色留给发送等主要操作。

项目工作约定

本页用一段示例文档对比聊天与文件正文的阅读表面。标题、段落、列表和行距保持一致，观察背景与外框对注意力的影响。

设计原则

  1. 工作区色用于身份识别和少数主要动作。
  2. 连续长文优先使用稳定的背景和清楚的文字层级。
  3. 选中项要可辨认，但不要处处都有悬浮阴影。

代码片段仍以局部底色区分，例如 src/renderer/src/styles，整篇正文则无需再套一个厚重容器。

文件树和阅读区属于不同功能，可以保留极浅的侧边线。左右虚拟屏也保留一根常驻浅线，帮助用户找到拖拽边界。
