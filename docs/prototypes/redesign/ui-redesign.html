现状诊断

它不丑，规矩也很全；问题在于「只有规矩、没有取舍」——每块都守规范，拼在一起却没有主次，也没有让人记住的瞬间。下面只谈视觉，功能与交互机制全部保留。

1

各区同一个灰，只靠 1px 线分开

顶栏、会话栏、主区、露边的工具页几乎同明度，视线没有落点；虚拟屏露出的那一条也只是「一截被切掉的灰」，看不出是另一张可以滑过去的屏。

2

顶栏像网页导航

「设置 / 工作区 演示-游乐场 / 全局看板 / 沙箱隔离」一排文字按钮，占掉一整条横向空间，和左栏职责重叠。

3

左栏信息挤、文字被截断

实用功能每行常驻快捷键；会话行里塞着运行时图标 + emoji + 名字 + 状态胶囊 + 时间，状态文字几乎总被截成「监听中 · 0…」。

4

调度栈功能对、视觉重

跨工作区对话是核心能力要保留，但每行都挂「空闲」「对话」两个同权重胶囊，三行就占了左栏近四分之一，也看不出哪一行是当前工作区。

5

聊天区控件层级平

待答横幅、排队面板里说明文字很多（「排队自动发送 0 条：Agent 空闲后按序发出」），常态下没内容也占着一大块；消息列、输入框、面板彼此没有轻重。

6

没有「品牌时刻」

规范禁止状态色以外的任何颜色，整窗全灰：分不出当前在哪个工作区，也没有一处让人觉得「这是精心设计过的」。

Frame & Sheet · 框与页

窗口是一个带工作区色调的「框」，侧栏直接画在框上；你正在处理的内容是浮在框上的「页」——会话页和工具页就是虚拟屏的两屏。借 Arc 的空间感与工作区配色，借 Notion 的排版克制与留白。灰阶仍是主体，颜色只出现在「你在哪」和「该你了」这两件事上。

保留不动的产品机制（只换皮）

KEEP

横向虚拟屏

工作页（会话栏 + 终端 / 对话）↔ 工具页（文件 / Git / 浏览器）同一条带平移；比例 7/8 与 2/3、悬停 280ms / 点击切页、分割条中段短按开关、长按切页模式与拖动调宽、按工作区落盘，全部沿用。视觉上：露边 = 一张纸的边缘 + 薄纱，悬停揭开并提示去向。

KEEP

跨工作区调度对话

左下调度栈每个工作区一行，任何工作区下都能点开任意工作区的调度 Agent；折叠堆叠、头像右键编辑工作区、「需要你」提醒都保留。视觉上：头像染该区颜色、一行摘要、当前区高亮；打开的对话面板染对方工作区色。

KEEP

会话栏折叠 / 速览、专注模式

左上 logo 仍是会话栏开关，折叠后左缘热区速览；专注模式仍从分割条长按菜单进入，会话页与工具页并肩。

KEEP

命令面板、快捷键、全局看板

Ctrl P / Ctrl Shift F 等全部不变；万能条只是命令面板的常驻入口。全局看板按钮从顶栏挪到侧栏顶部图标排，中键 / Ctrl Shift G 照旧。

五条设计原则

01

框与页，主次一眼可见

框（窗口底 + 侧栏）退后、带色调；页（会话页 / 工具页）浮起、纯净、带柔和阴影。取消独立顶栏，窗口按钮直接落在框上。

参照：Arc 的内容窗浮在侧栏之上
02

一个工作区一种颜色

每个工作区一个色相，只用在：框的渐变、logo、调度头像、发送键、运行中的旋转弧。切工作区时整窗色调过渡。现有「工作区独立主题」机制可以直接承载。

参照：Arc Spaces
03

字优先，线退场

分区靠字重、留白和海拔，几乎不画分隔线。对话正文居中阅读列 ≤ 760px、15px / 1.7；助手消息无气泡像读文档，用户消息是右侧轻气泡。

参照：Notion 页面排版
04

状态用形状，不用长字

四个状态图形（旋转弧 / 跳动黄点 / 绿勾 / 空心圈）贯穿侧栏、页头、看板。自由状态文案保留，但放到第二行浅色，不和名字抢位置。

参照：Linear / Arc 标签页状态
05

安静的默认，鲜明的时刻

全界面只有两处高饱和：「需要你」的黄色卡片（带柔光）和发送键。其余一律灰阶；没东西时不占地方（排队面板折叠成胶囊）。

参照：Things / Notion 的空状态克制
06

动效沿用现有体系

时长 / 曲线全部用现有 --dur-* / --ease-*，进出场仍走 usePresence。新增的只有「切工作区时色调过渡」一处，需要登记为动画规约例外（或改两层底色交叉淡入）。

约束：docs/features/animation-system.md

动手前需要你知道的影响

  • design.md 要重写：它是全部 UI 的「唯一裁决标准」，现在明确规定了零色偏、禁止装饰色、静态卡片禁阴影、分隔线白名单、圆角 12/16/24。新方案和这些条款直接冲突，落地第一步是改规范本身（相关守卫测试随之调整）。
  • 主题 JSON 要加字段：新增「框」底色与工作区强调色；内置深 / 浅主题和用户自定义主题需要一次迁移（缺字段自动补默认值）。
  • 去掉顶栏牵动窗口外壳：Windows 右上角系统按钮依赖 36px 标题栏覆盖区，侧栏顶部要接管拖拽区；右栏开合钮、会话栏折叠、专注模式、窄屏抽屉要一起回归。
  • 虚拟屏几何要重核：页之间多了 8px 缝与圆角，终端 fit、截图拼接（切区骨架）、调宽快照模糊卡都按新几何校准；比例与落盘字段不变。
  • 动画规约有一处例外：切工作区的色调过渡不是 transform / opacity，需要登记（或改成两层底色交叉淡入，保持合规）。
