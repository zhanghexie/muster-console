发布方案筛选方案、比较投入，再选一项继续讨论。 图表和列表使用同一筛选条件。悬停查看完整数值。

先选定目标和预算，再比较方案。费用只是一个维度，也要看交付范围、迁移成本与外部依赖。

列表支持排序、筛选和选择。表格的操作与详情中的继续提问使用同一份选择，切回会话后仍可接着操作。

长内容默认直接铺在会话中。鼠标落在表格、图表或数字输入框上，普通滚轮仍然滚动会话，避免嵌套滚动影响阅读。

需要减少占用时使用上方“收起”。收起与展开不会重建内容，参数、选择与排序会保留。

窄布局会把并列分组改为单列。图表按实际宽度重新计算刻度和标签，表格需要时可横向查看。

筛选与参数等公开选择可用于下一轮讨论；页签、排序和私人显示偏好仅用于恢复界面。
