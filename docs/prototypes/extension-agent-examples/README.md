# 扩展 Agent 交互示例

这是设计验证原型，用一个宿主侧边栏展示人和 AI 共同操作同一个扩展状态。

- 日报：人可以勾选和新增待办，AI 可以读取昨天的工作、查询未完成项和新增明天的待办
- 五子棋：人可以直接点击棋盘落子，AI 可以读取二维棋盘、分析局势、推荐位置和落子
- 书架：人可以选择、分类和归档书籍，AI 可以统计阅读、读取当前选中书籍和按类型整理

AI 侧边栏可以随时关闭和打开，打开时自动绑定当前扩展实例。主界面的按钮和 AI 调用同一套领域操作，操作结果通过共享状态立即回写到主界面。页面只模拟交互，不代表产品实现。

打开 `extension-agent-examples.html` 后，直接操作左侧界面，再在右侧输入框尝试「我昨天干了啥」「给我加个明天的待办」「帮我下两步」「整理下我的书架，按类型分类」等请求。动效使用原型级 token，正式实现需要接入工作台的 motion/presence 体系。

从仓库根目录运行 `node docs/prototypes/extension-agent-examples/extension-agent-examples.smoke.cjs` 可以复验人操作同步到 AI、AI 操作回写主界面，以及侧边栏关闭和重新打开。
