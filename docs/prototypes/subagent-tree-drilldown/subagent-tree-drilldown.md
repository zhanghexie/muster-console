# 子代理通用化原型 · 左栏树 + 下钻面板

验证 子代理通用化计划 的两条产品形态决策：**D1 左栏完整树**（父子链总深度上限 3 层）与 **D2 下钻式面板**（整页切换 + 顶栏层级路径）。

静态演示，不接真实会话。预览：直接用浏览器打开 `subagent-tree-drilldown.html`，无构建步骤。

## 演示了什么

**左栏树（D1）**

- 三个顶层会话；「重构认证模块」下挂两个子代理，其中「补认证测试」再挂一个孙代理——演示完整三层
- 每层缩进 16px，每行有 twisty 可折叠/展开自己的子树；当前选中项走选中态叠层
- 虚线连接符图标表示子层级，实线方框表示顶层会话
- 状态胶囊：运行中（呼吸点）/ 已完成 / 待验收
- 底部**灰显一行「曾代理（已被深度上限拒绝）」**——父子链总深度上限 3 层，第 4 层即拒

**下钻面板（D2）**

- 点任意子层级 → **整页切换**到它的转写流（不是合并、不是并排）
- 顶栏是层级路径面包屑：`会话 重构认证模块 › 子代理 补认证测试 › 孙代理 核对并发用例`，点任一级回跳，类文件管理器进文件夹
- 面包屑的层级标签区分「会话 / 子代理 / 孙代理」
- 子层级视图的输入框带 accent 左缘，提示行显示「继承 Pi · 同一模型 · 同一目录」
- 派出下一层的那条消息带「派生了下一层」标记，下方挂**子代理卡片**（名称、状态、继承信息、「查看进展 ›」）

**子↔父通信（D4/D5）**

- 子代理完成 → 父会话收到注入卡（「已回报父会话」），可点击回子代理
- 子代理中途提问 → 展示注入卡（「已向父提问」），可点回父会话
- 父会话里也能看到子代理完成注入（「来自子代理」）

**继承信息（D8）**

每张子代理卡片与子层级视图的提示行都标出实际继承到的 harness 与模型。注意第二个顶层会话的子代理标 **Claude**——说明子代理不再锁死 Pi。孙代理继承其父（子代理）的配置，符合「凡有父即继承」。

## 交互清单

| 操作 | 结果 |
| --- | --- |
| 点左栏任意行 | 整页切换到该会话；子代理则带面包屑 |
| 点行首 twisty | 折叠/展开该行的子树（不切换会话） |
| 点面包屑任一级 | 跳回该级会话 |
| 点子代理卡片「查看进展 ›」 | 下钻到该子代理 |
| 点注入卡「查看 ›」/「回到父会话 ›」 | 双向跳转 |
| 右上「切换浅色」 | 深/浅主题对照 |
