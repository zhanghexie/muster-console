设计说明

设置页统一骨架提案（沉浸版）：全部页面同一个列宽，去掉节级卡片盒子，区域划分靠节标题、字阶与留白。token 不动，只收编结构与控件。

现状诊断：七类不统一

① 内容列宽不一
现状普通页 760px、模型服务商/文本工具 1000px、关于页更窄；切页时正文左右边界跳动。
提案所有页面统一 920px 单列，居中；主从页不再加宽——直接取消左右分栏。
② 卡片盒子太重
现状每个分区套一张 L2 卡片，设置页看起来像一堆浮起的盒子，页面被卡片的边框切割。
提案内容直接铺在页面上（沉浸）；区域 = 节标题（14/500）+ 40px 区距 + 行；线条只给表格型列表（目录、键位表）。主题缩略图、二维码这类「内容对象」保留自己的形。
③ 行文法混乱
现状布尔项三种写法：行+开关 / 裸勾选+长句 / 标签忽左忽右；模型列表、记忆表单、Shell 表单各是一套字段排版。
提案只允许三种行：设置行（左标题+说明、右控件）、字段行（标签在上、控件整行）、列表行（图标+名称+徽标+meta+右动作，可展开）。
④ 控件多套皮肤
现状按钮有 btn / ui-btn / cm-button 三套；分段选择有 s-seg / weekday-toggle / llm-capsule 三套；输入框高度不一。
提案控件收敛为一套：开关、分段（含启用/禁用胶囊变体）、选择、输入；按钮四档（主/次/幽灵/危险描边）+ tiny。
⑤ 保存语义标记随缘
现状通知每张卡都挂「随保存生效」，Worker 个别卡挂「即时生效」，其余页没有标。
提案随保存生效是默认、不打标；只有「即时生效」的节头挂蓝点 tag。标记从卡片级上收到节级。
⑥ 危险动作位置随机
现状红色「删除」出现在页头、卡头部、列表行内、卡片中间，有的红字有的描边。
提案破坏性动作一律放所属区块最后一行右侧（前加 hairline 分界），红描边 + 两步确认；行内小动作用幽灵 tiny + 红字。
⑦ 同类控件异形、排布与逻辑不符
现状能力管理范围切换独带 emoji（全应用唯一）；「待处理差异」（队列）与 Skills/MCP（资源类型）并排成页签；同为布尔项，有的用开关、有的用启用/禁用胶囊、有的用浮条胶囊；同为文本输入，服务商整行、记忆页右置半行。
提案同类控件同形：布尔一律开关，多选一一律分段（不设胶囊变体），输入框一律字段行（标签在上、控件整行）；页签只放资源类型，待办队列（同名差异）降级为列表上方的过滤胶囊，点击只看有差异的条目；作用域切「全局」时项目选择器禁用。

统一骨架

页页头 = 20px 标题 + 一句 lead；所有页面同一列宽 920px，内容直接铺在 L1 页面上
节节标题 14/500 + 右侧槽（动作按钮 或 「即时生效」tag）+ 可选一句灰色说明；节与节之间 40px 留白
行设置行 / 字段行 / 列表行；控件归一：布尔一律开关、多选一一律分段、下拉在设置行右侧、输入框一律字段行；技术细节收「高级」折叠；表格型列表（目录、键位）行间用 hairline
