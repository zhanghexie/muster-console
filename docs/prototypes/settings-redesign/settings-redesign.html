设置界面重设计

方向：从「一个塞满说明文字的弹窗」改成「一张安静的设置页」。和主界面同一套「框与页」：左边导航画在窗口底上，右边内容是一张圆角页。功能一项不少，只改呈现、分组和保存方式。

现在的问题 → 改法

#现在的问题改法
1保存规则混乱：有的「即时生效」，有的「随保存生效」，有的卡片里还有自己的「保存 Shell 设置」按钮，底部又常驻「保存/取消」去掉所有「即时生效/随保存生效」标签和卡内保存按钮。需要保存的项被改动后，底部才浮起「有 N 项更改未保存 · 撤销 · 保存」条（Ctrl S），没改就不出现。即时生效的项照旧即时
211 个页面平铺，每项还带一行小字描述，名称是内部叫法（能力参考、Worker 终端、Runtime）四组带图标：常用 / AI / 连接 / 其他；改名：能力参考→调度 Agent，Worker 终端→Worker，远程连接→远程访问；新增「通用」页收拢语言、字体、防休眠、自动日志
3说明文字满是路径和字段名（~/.pi/agent、runtimeOverrides、bgtasks.shell、reasoning_effort）每项只留一句人话说明；路径、协议字段收进「高级」折叠区或直接删掉（开发者参考保留入口）
4勾选框、整行宽下拉框、表单堆叠，读起来像配置文件统一「行」布局：左边标题 + 一句说明，右边控件（开关 / 分段 / 下拉）；同类项装进一张卡，行间细线
5设置里不能搜索（只能在命令面板里搜）导航顶部加搜索框，复用命令面板已有的设置索引（数据现成），回车直达并高亮那一项
61200×860 固定弹窗，内容多的页（模型、远程）挤在里面滚动整窗设置页，内容列最宽 760 居中；Esc / 「返回工作台」回到原来的会话
7远程连接一次列 5 条长网址 + 大二维码一条推荐网址 + 二维码作主角，其余网址折叠；「重置密钥」挪到单独的安全区
8主题只有下拉框，看不到长什么样主题做成缩略图卡，点一下即切换

不变的

所有设置项、它们各自「即时生效还是需要保存」的规则、写入的配置位置、命令面板里的设置搜索跳转（focusItem 高亮），全部保持。
