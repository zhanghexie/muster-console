# 右侧统一多标签原型

2026-10-09 的设计验证稿。左边保留统一内容标签与查看现场，右边资源树跟随当前内容标签，也可通过紧凑的图标胶囊手动切换。交付只包含独立原型，尚未接入生产 `SideToolsPanel`、Electron、IPC 或真实仓库操作。

## 已对齐的规则

| 事项 | 用户确认的方案 |
| --- | --- |
| 内容标签 | 文件、图片、网页、Git 仓库与独立 Diff 并排打开 |
| 归属 | 普通标签跟随会话；Pin 在同一项目的会话间共享 |
| 文件树 / 搜索结果 | 单击复用临时预览标签；双击或开始编辑后保留 |
| 聊天交付物 | 默认新开普通标签；已打开的内容直接聚焦，保留审核现场 |
| 前进 / 后退 | 跨文件、图片、Git 与网页回放当前会话整个右侧的查看历史 |
| 顶栏 | 尽量一行，通过间距、底色与分割线明确功能层级 |
| 右侧三个图标 | 恢复原三段式胶囊，文字换成文件 / Git / 浏览器图标；手动点击只切右侧面板 |
| 内容标签联动 | 切换内容标签时，文件 / 图片对应文件树，Git / Diff 对应仓库树，网页对应收藏夹树 |
| 面板连接 | 三个图标始终紧凑放在最右边；去掉顶栏竖线，内容区保留分割线 |
| 收起 / 展开 | 按钮固定在三个图标旁边的顶栏，面板内部不放收起按钮 |
| Git | 每个仓库一个内容标签，内部有变更 / 历史 / PR；具体 Diff 可以独立打开 |
| 浏览器原右栏 | 网页页签统一放到顶部后，原右栏改为收藏夹树 |
| 所有标签按钮 | 删除；直接横向滚动内容标签，活动标签自动滚入可见区域 |

历史按当前会话分别保存，不通过前进后退切换会话。取消 Pin 后，标签留在当前会话；批量关闭其他 / 右侧会话标签保留项目 Pin，单独关闭 Pin 仍关闭该共享标签。这些细则是原型提案，尚非生产契约。

## 分区与资源树

顶栏左边依次是历史导航、内容标签、新建标签、当前内容工具；最右边恢复三段式图标胶囊，旁边固定收起 / 展开按钮。顶栏不设置竖向分割线，内容区与资源树之间保留竖线。内容工具独立包在浅色区域里，随左边当前内容改变。胶囊为 96×28px，外圆角 9px，选中项为独立的浅色内胶囊，不再向下延伸连接资源面板。三个图标在面板展开与收起时都为 28px；窄布局都为 24px，间距不因开合变化。图标有可访问名称和悬浮说明。

文件树包含项目目录、源码目录、文件和图片，搜索文件与所有文件中搜索放在文件面板栏头；编辑 / 预览、当前文件内查找、在树中定位属于左侧当前文件工具。定位展开该文件的祖先目录，不增加查看历史。目录仅用文件夹图标表现开合，不额外增加三角图标。

Git 面板显示工作区、嵌套仓库和外部仓库。点仓库打开或聚焦左侧仓库标签；可展开的仓库行同时切换子树。仓库搜索与刷新位于右侧，变更 / 历史 / PR 与同步位于左侧当前仓库。仓库树与仓库内容中的变更文件列表承担不同职责。

浏览器面板显示收藏夹与嵌套文件夹，即使左边仍在看图片或审核代码也可打开。点收藏在顶部打开普通网页标签，同网址已打开则聚焦；关闭标签保留收藏与原页面草稿。网址、刷新、元素选择和开发者工具属于左侧当前网页。收藏树与 Pin 分别负责网址收纳和项目共享标签。

右侧三种面板的选择、展开目录和收起状态由 `resources` 管理。打开、选择、历史回放、关闭后替换、恢复关闭标签与会话 / 项目切换，均按当前内容类型更新右侧树；即使重新点击当前标签，也会恢复其对应面板。联动保留各树展开目录和面板收起状态，避免切换内容时意外展开。手动点击胶囊只切面板，不改变左边内容、标签或查看历史；下一次内容导航重新跟随内容。载入旧原型状态时兼容 `browserUi` 的收藏目录展开信息，并按当前内容确定初始面板。宽布局右侧为 216px；右侧工作面不超过 600px 时改为 176px 浮出层。顶栏按钮可收起 / 展开当前面板，点任一胶囊图标也能恢复。

标签关闭与 Pin 在悬浮或键盘聚焦时显现，当前标签始终露出关闭入口。标题不足时截断，保留完整路径提示。当前工具的快捷图标在窄布局收进更多菜单；新建、关闭、关闭其他 / 右侧、恢复和 Pin 通过顶栏、标签右键菜单与快捷键操作，不额外设置所有标签列表。定位信息如标题、路径、网址、分支保留文字。

## 建议体验

1. 初始处于代码审核，右边能直接看到仓库树。点聊天的 `prototype.png` 新开图片标签，右边自动变为文件树；点网页标签自动变为收藏夹，点 Git 或独立 Diff 自动变为仓库树。
2. 手动点胶囊可在图片保持不变时查看三种树；再点内容标签恢复跟随。点后退回到 Git 时右边也回到仓库树，前进回图片时回到文件树。将图片 Pin 到项目，切换代码审核 / 界面开发，再切换项目确认共享范围。
3. 点文件树里的文件，单击复用预览，双击或开始编辑保留。切换右侧面板、打开聊天图片后返回，编辑稿保留；搜索文件与所有文件中搜索也可从文件面板使用。
4. 点仓库树的嵌套仓库打开审核，再将具体 Diff 独立打开。增加多个内容标签，观察横向滚动、当前标签自动显示及标签右键菜单。
5. 左边仍看图片时切到收藏夹，展开设置页 / 开发参考并点收藏；重复点击确认去重，关闭网页标签确认收藏仍在。缩窄窗口，收起右侧面板后切换内容标签，胶囊选中项跟随但面板保持收起，再从顶部恢复对应树。

原型还提供内容标签左右键切换、右侧面板页签左右键切换、Alt+左右历史、Ctrl/Cmd+W 关闭、Ctrl/Cmd+Shift+T 恢复，以及同一归属组内的拖动排序。上述快捷键仅在原型区域内生效。

## 实现与复现

- 状态与组件：[side-tools-tabs.tsx](side-tools-tabs.tsx)。`reduceTabs` 管理打开来源、预览复用、会话 / 项目归属、关闭恢复、历史与资源面板。回放旧临时预览不会覆盖后来编辑的文件。
- 样式：[side-tools-tabs.css](side-tools-tabs.css)。产品深浅主题与 6px 页缝；菜单、面板和树使用现有 `usePresence` / `usePresenceValue`、`MOTION`、`acc` / `mp-panel`。动画 token 从 `base.css` 提取。
- 生成器：[build-side-tools-tabs.mjs](../../../scripts/build-side-tools-tabs.mjs)。生成同名 HTML 片段，内嵌 React 与附件图片，Lucide 由预览宿主提供。
- 组件测试 spec（side-tools-tabs-prototype.spec.tsx）已于 2026-10-10 测试清理移除：生产行为已由生产 SideToolsPanel spec 等价覆盖；浏览器布局回归仍用下行 check.js。
- 浏览器布局回归：[side-tools-tabs-prototype.check.js](../../../test/e2e/side-tools-tabs-prototype.check.js)。Playwright CLI 的 `run-code` 回调，检查图标胶囊、内容与右侧树联动、手动切换保留内容、收起时联动、会话切换、顶栏位置、活动标签滚动、768 / 480 / 320px 布局与收起恢复；不是生产 Electron 测试，也不会被 `.spec.ts` 的 E2E 配置自动运行。

生成：`node scripts/build-side-tools-tabs.mjs`。HTML 是对话片段，先用 visualize 技能的 `scripts/render.py` 包装，再本地预览：

```text
python <visualize-skill>/scripts/render.py <absolute-path>/docs/prototypes/side-tools-tabs/side-tools-tabs.html <absolute-path>/output/playwright/side-tools-tabs/preview.html --force
node scripts/build-side-tools-tabs.mjs --serve
```

`--serve` 只在 localhost 提供已包装的 `preview.html`，端口由终端输出。`--visual-copy <absolute-path>` 将片段复制到当前对话授权的预览目录。组件在支持的对话宿主中通过 `widgetState` 保存有意义的交互，载入时不主动写入。

从仓库根目录打开本地页面并取得新的浏览器快照后，可用 Playwright CLI 运行布局回归；Windows 的包裹层若吞掉多行参数，使用已安装 / 缓存的实际 CLI 入口：

```powershell
$taskCheck = Get-Content -LiteralPath 'test/e2e/side-tools-tabs-prototype.check.js' -Raw
playwright-cli --session=right-tabs-prototype run-code $taskCheck
```
