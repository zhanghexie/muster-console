# Skills 与 MCP 管理交互原型

本原型承接 开源项目调研，用于评审管理交互。它使用独立示例数据，尚未接入正式设置页、目录扫描或 Agent 运行时。

## 体验入口

- [单文件交互原型](skills-manager.html)，可直接在浏览器打开；刷新后恢复初始示例。
- [组件源码](skills-manager.tsx) / [样式](skills-manager.css)。
- 生成并启动本机预览：

    node scripts/build-skills-manager-prototype.mjs --serve

- 深色默认，浅色可加查询参数 ?theme=light；右上角按钮随时切换。
- 演示操作在“试一下”菜单里，可模拟 CLI 创建技能或重置数据。

## 交互取舍

正式入口已按用户裁决确定为“设置 → 能力管理”，内部包含 Skills、MCP 和待处理差异，复用设置整窗外壳。用户明确不增加实用工具入口，早期快捷入口建议已取消。当前独立原型保留作评审记录，正式实现见 [能力管理](../../features/capability-management.md)。

1. **先选作用范围。** “全局”只显示全局内容；“当前项目”分成“仅当前项目”和“来自全局”。切换项目不会把另一项目的技能混进来。
2. **继承关系可见。** 项目页的全局继承项只读，通过“在全局管理”进入对应设置，避免一次项目操作影响其他项目。
3. **内容来源与使用关系分开。** 列表先看名称、来源和关联的 Agent，详情再显示原目录、附带文件和逐入口关联。原目录不代表创建者，也不代表某个会话已经加载。
4. **同一份内容多处使用。** 编辑弹窗说明共享修改影响；关联保存后显示“待刷新”，不给已有会话显示虚假的即时生效。
5. **外部新建保留原范围。** 模拟 Claude 用户目录/项目目录的新技能自动进入清单，并继续引用原目录。它可关联 Codex 等其他入口，不自动升为全局。
6. **同名不同源继续可见。** 对比两份正文后可以保存使用偏好；原文件、原关联和外部差异提示都保留。保存偏好不等于 CLI 原目录的重复项已经处理。
7. **MCP 配置与连接分开。** 关联和“未验证 / 示例握手成功 / 需要认证”分开展示。配置存在不等于可调用。

示例入口明确区分 Claude Code CLI、Codex CLI、Cursor GUI 和 Pi SDK，不把同一产品的 CLI、GUI、SDK 假定为一个生效目标。完整入口矩阵、配置投影和真实加载证据属于后续实施。

## 已实现的演示操作

- Skills / MCP / 待处理差异切换；全局、项目与两个示例项目切换。
- 搜索、按 Agent 筛选、空结果状态。
- 关联勾选、保存与下次打开保留；正文编辑、取消与保存。
- 模拟外部技能发现、跨入口关联；同名版本对比与使用偏好。
- 模拟 MCP 握手成功、认证需求；深浅主题。
- 窄窗口详情抽屉、遮罩、Escape、焦点移入/恢复和 Tab 约束；弹窗使用同样的键盘约束。

动画直接复用正式 usePresenceValue 与 base.css motion 骨架，颜色、字号、圆角和焦点使用正式 token。单文件预览不加载外部字体，按正式字体栈回退到系统字体。

- 截图和 manifest 在 .tmp/ui-captures/skills-manager-verified，QA 总览为 index.html；已实际查看深浅首屏、窄窗口详情与两份正文对比。
- 首轮浏览器捕获拦截了关联草稿残留：详情切换后勾选可能沿用前一项，紧接的新输入可能被 effect 覆盖。通过按资产 id 初始化 Detail、仅在关联数据变化时同步草稿修正；真实触发路径和组件回归均通过，失败证据保留在 .tmp/ui-captures/skills-manager。
- 构建产物为内联 React 单文件 HTML，本机服务仅绑定 127.0.0.1，只提供原型页面。
- 示例状态只在页面内存中保存；不会读写真实 Skills、CLI 配置、MCP 服务或凭据。
- 本轮不证明目录监控、文件链接、外部配置同步、真实连接、会话刷新或 Electron IPC 已实现。
- 原型仅评审交互；正式开发需补可执行实施计划，并按具体入口验证发现、配置和加载链路。
