# 桌面首次设置

## 界面与流程

桌面首次收到空工作区快照时挂载真实工作台。工具检测和模型介绍用原生模态对话框覆盖在工作台上，通过轻度背景模糊保留顶栏、侧栏和中央区的轮廓。原生对话框管理背景的焦点和点击，卡片随统一动效进出场。窄窗下引导内容可滚动。

1. **本机工具**。用户可检测或跳过。内置 Muster Core 始终可见。检测先通过 `runtimes:availability(true)` 刷新 PATH 和预检，再通过 `agentSession:listHarnessPickerChoices` 获取接入状态。实际登录由各工具管理。
2. **连接模型**。「去模型设置」进入正式的「设置 → 模型与输入 → 模型服务商」。全新配置没有预装服务商或默认模型，旧 OpenAI 连接字段也为空；已有明确保存的配置保留。模型提示分为「添加供应商 → 连接配置 → 添加模型 → 默认与保存」四步；添加供应商后自动进入连接配置，直接指向真实 API Key 输入框，未填写地址的自定义端点同时提示填写 Base URL，再点「下一步」。添加模型优先指向「模型列表」标题动作区的「从目录添加」，没有可选候选时回退「＋ 添加模型」；实际选好模型后自动进入默认与保存步骤。进入步骤会将目标滚入可见区域，编辑草稿不反复抢滚动。目录或模型编辑弹窗打开期间隐藏提示卡。供应商、密钥、多个模型与连通性测试沿用设置原有流程。「返回引导」遵循未保存确认。返回时宿主读取已保存的 Core 默认模型配置，有可用配置结构时推进；未完成时模型介绍明确显示当前缺项，再次打开设置直接定位待补的步骤。仅使用本机工具的用户可稍后配置。
3. **工作区**。背景恢复清晰，提示卡指向真实的「工作区 ＋」。点击进入常规创建窗口，可确认推荐目录或用原生选择器选已有文件夹。推荐目录只在确认创建时落地。创建成功后进入下一步。
4. **第一条会话**。提示卡指向真实的「工作会话 ＋」，折叠时先指向打开左侧栏的入口。使用常规「新建任务」窗口创建会话，或选「稍后创建会话」直接进入导览。
5. **工作台导览**。依次指向左栏开关、右栏开关、虚拟屏、全局看板和主题。窄窗口的侧栏提示指向实际抽屉按钮，虚拟屏步骤提示可在宽窗口体验。虚拟屏默认点击露条切换，分隔条的长按菜单可以改变切屏方式。看板未打开时，提示同时介绍顶栏入口、鼠标中键和当前 `globalBoard.toggle` 快捷键；快捷键标签由 `useChordLabel` 按当前绑定与平台格式显示，未绑定时仅介绍中键并指向「设置 → 快捷键」配置入口。看板打开后，提示移到其「状态｜自由」切换器，并指出右上的筛选和新建入口。离开看板步骤时收起看板。主题步骤进入正式「设置 → 外观」，由真实主题卡片即刻应用。导览支持上一步、下一步和整段跳过。
6. **完成**。「准备就绪」展示已创建的工作区、已打开的会话和已保存的默认模型。远程访问和延后的项目通过「稍后设置」保留入口。点击「开始使用集序」才写入完成状态，返回工作页并尝试聚焦可见的会话输入框；未创建会话时进入普通空状态。

锚定提示随目标位置更新。工作台引导可见时，鼠标和键盘只操作高亮的真实控件及提示卡；看板步骤也接受看板的鼠标中键和当前快捷键。目标暂不可见或打开对应的建区、建会话弹窗时，提示卡退场并释放交互限制。关闭引导将当前步骤暂停，工作台顶栏的「继续新手引导」可在同次使用或重启后恢复。完成过设置的桌面用户关闭最后一个工作区时，待工作区关闭事务结束后进入独立的建区恢复页。

## 状态与入口

| 入口 | 职责 |
|---|---|
| `src/renderer/src/RootLayout.tsx` | 等待工作区快照，调和已创建的工作区和会话与当前步骤；从正式配置确认默认模型。网页、移动和独立扩展窗使用各自入口。 |
| `src/renderer/src/onboarding/setupProgress.ts` | Electron profile 内的 `muster.firstRun.v1` 保存步骤、延后项和暂停状态。支持旧版步骤字符串和 JSON，旧远程访问步骤衔接到创建工作区，旧完成状态保持完成。 |
| `src/renderer/src/onboarding/FirstRun.tsx` | 原生对话框、工具检测、正式模型设置跳转和零工作区恢复页。 |
| `src/renderer/src/App.tsx`、`components/ChromeBar.tsx`、`panels/BoardPanel.tsx` | 同一工作台上切换模态与实操引导，绑定两侧开关、虚拟屏和看板的真实控件。 |
| `src/renderer/src/onboarding/SetupCoachmark.tsx`、`WorkbenchSetupGuide.tsx` | 定位提示、目标描边、完成与延后入口。根据可见锚点、滚动、缩放和折叠重算位置。 |
| `components/settings/SettingsModal.tsx`、`ModelProviderPane.tsx`、`ThemePane.tsx` | 在正式设置页展示模型和主题提示，通过既有保存、未保存确认和关闭逻辑返回引导。 |

## 验证入口

`test/unit/first-run.spec.tsx`、`test/unit/setup-coachmark.spec.tsx` 和设置页的组件测试覆盖首屏、引导转交、定位以及未保存确认。`test/e2e/zero-workspace-onboarding.spec.ts` 通过隔离的正式数据路径启动真实 Electron，覆盖正式模型配置、建区和会话、暂停续办、导览和完成页。开发沙盒自带演示工作区，首装验收使用空白的临时数据目录。
