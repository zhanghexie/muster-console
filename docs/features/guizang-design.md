# 歸藏设计

源码与扩展级回归位于 [muster-extension-guizang-design](https://github.com/zhanghexie/muster-extension-guizang-design)。扩展目录为 `guizang-design/`。

上游版本与许可见包内 README。清单声明 sidebar、五份技能、工作区数据和领域工具。

- `gallery/panel.html`、`gallery/app.js` 通过宿主 SDK 读取中英文目录、六个工作流和官方示例，跟随宿主语言与明暗。点技能、工作流或「做同款」会打开当前项目的「新建任务」弹窗，预填可编辑草稿与技能胶囊，取消不会留下空会话。图片使用宿主选择器与实例媒体 URL，官方 HTML 示例经宿主导出后在当前工作区右侧浏览器标签播放，支持页面的点击、键盘和本地存储。
- `domain.mjs` 用 data broker 保存作品索引和语气档案。新任务把文件写入项目，作品库保存相对路径及宿主提供的来源引用（侧栏使用绑定项目的稳定引用，独立任务使用任务 ID）；点击作品在右侧打开原文件，「继续修改」回到来源任务。重启后，只有旧会话 ID 的历史条目在首次打开时提示确认当前项目中的文件，成功预览后保存新引用。项目 HTML 与以前单独保存的 HTML 正文都在卡片进入视野时生成离线首屏缩略图。图片作品直接展示媒体资产。作品按 ID 更新，移出仅改变目录。面板监听 state.changed，Agent 可用同一组命令登记作品或修订档案。
- `skills/` 保存技能及相对资源。内置助手用 skill.read 读正文，从返回的 skillRoot 定位渲染脚本，用可选 resource 参数读模板，skill.location 可查询包内示例。宿主不代装 Playwright、浏览器或字体子集工具。单个 HTML 正文受宿主数据文件 1 MiB 上限约束。
- 独立仓库的 `test/domain.mjs` 检查技能文件和域数据往返，运行实际渲染脚本。`test/gallery.spec.tsx` 检查预填草稿与编辑交互。

平台缺口和验收场景见 扩展改造计划。

作品卡片移出通过 `ma.ui.confirm` 使用宿主确认框；确认前不发领域命令，取消保留作品，确认后仅移出索引，保留项目文件。请求期间禁用原按钮，避免重复提交。

面板外壳、导航与操作控件使用 SDK 主题，瑞士配色保留在技能横幅和产出模板中。搜索只更新结果区，输入法组合期间保留输入节点。视图重绘会取消已卸载横幅的观察与绘制回调。
