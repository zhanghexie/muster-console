# 面板与内容历史

## 功能职责

顶栏左侧的 ‹ › 与 `Alt+←/→` 回放左侧面板、会话、中央分屏和虚拟屏切页。右侧内容标签旁的一对「撤销」「重做」与 `Ctrl+Alt+←/→` 回放右侧操作。两侧按钮的提示分别显示可用步数与实际快捷键，改绑即时更新，解绑时隐藏快捷键。

左侧由 `PanelHistoryProvider` 管理，每工作区独立双栈，上限 20。一次访问是完整的左侧视图快照：单屏主内容，或分屏的主/副/第三逻辑槽、物理顺序、方向、比例（含三分屏两个物理边界坐标）与焦点。切换内容、开关分屏、关闭某格、重排布局会产生访问；仅切焦点、调比例不产生新步骤，但更新当前快照，下一次离开时仍能恢复这些信息。回放直接恢复逻辑槽，绕过普通侧栏选择的“填当前焦点格”入口。

切到右侧虚拟屏只记录一个 `{ page: 'git' }` 访问，不含文件、仓库、标签或网页身份。在右侧内部切换内容不增加左栈；前进回右侧时保留右侧当前内容。虚拟屏显隐、专注和宽度偏好继续由布局体系管理；历史只记录当前页，重新进入右页时如有需要会展开右侧。

右侧使用[统一多标签状态机](right-workspace-tabs.md)。每个工作区和会话最多保留 60 个操作，按顺序记录打开标签、关闭标签、同一标签切换内容及网页导航。批量关闭记一步。点选已有标签、资源切换、单纯刷新和后台同步不入栈。撤销与重做恢复受影响标签及其选择，资源类型跟随内容，保留资源面板的收起状态。执行新操作时丢弃重做分支。

## 回放保护与边界

- 左侧按分屏事务完成确认隔离回放，不再用 250ms 时间窗吞事件。慢 IPC 不反入栈，确认后的快速真实导航立即记录；失败保留确认过的布局并撤销历史移动。工作区切换/水合只重置观察基线，不清除各区历史。
- 右侧回放等待文件保存及网页或扩展位置确认。浏览器回执关联到原标签，回放产生的快照不重复入栈。失败时保留可重试的历史位置并显示错误。
- 正在确认的主选中与临时布局不进入左栈；连续历史操作等待本次回放确认。已删除/归档会话、失效工具等主目标跳过；失源的非主槽降为空选择器并保留布局。scheduled 可回放为单屏，不扩展其分屏能力。
- 临时文件预览在同一标签回放。原预览被用户保留或编辑时，继续保留原编辑器，用临时标签呈现更早的文件。文件来源根失效时沿用已有拒绝规则。
- 网页历史保存 Chromium 已提交的位置，同 URL 的不同历史项也能区分。撤销关闭时，在新 guest 中恢复 Chromium 历史并绑定原右侧标签。位置在当前 guest 的原生栈内时，用原生前进后退切换。
- 左侧历史、右侧操作历史与 Chromium 回放数据保留在内存。保留标签、Pin、每会话选择与布局偏好另走工作区偏好。
- 回归：`test/panel-history.mjs`、`test/unit/panel-history.spec.tsx`、`left-navigation-history.spec.tsx`、`center-split-store.spec.ts`，右侧 `right-workspace-{model,ui,browser}.spec.tsx`。
- 真实 Electron：`test/e2e/window-navigation-history.spec.ts` 覆盖工具/会话回放、副格切换、虚拟屏切页、左右按钮和快捷键隔离、关闭副格后恢复、窄态槽位焦点和前进分支保留；截图在 `output/window-navigation/`。右侧的文件预览、开网页、原生导航、关网页连续撤销和重做见 `test/e2e/right-workspace.spec.ts`。组件测试不代替原生窗口与网页验收，源码构建也不代表已安装客户端已更新。

## 设计初衷（2026-10-26 与用户定稿）

> 依据 campaign-intent-drafts/D07.md 草案定稿（用户 2026-10-26「不抽查直接定稿」）；歧义点处置：22 项卡片决策＋长尾按草案推荐，明细见专项账本「意图定稿决策」节。

- 为谁/什么场景：顶栏 ‹ › 两套独立历史——左侧回放面板/会话/分屏/虚拟屏切页（Alt+←/→，每工作区双栈上限 20），右侧用撤销与重做回放统一多标签操作（Ctrl+Alt+←/→，上限 60）；悬浮提示显示步数与当前绑定。
- 为什么这样设计：左侧快照是完整视图（含分屏槽位/物理顺序/比例/焦点），回放经 centerSplitRestoreHistory 原子恢复绕过「填当前焦点格」；按分屏事务完成确认隔离回放（不用时间窗吞事件，慢 IPC 不反入栈）；仅切焦点/调比例不增步但更新当前快照；右页只记 {page:'git'} 不含资源身份（右内容归右侧栈）。
- 明确不做：不跨重启保存（浏览器语义内存栈，重启从当前选中+默认中栏开始——ui-state-persistence §4 已拍板）；失败回放撤销游标不重试；原生 guest 已关闭时创建新 guest 并恢复导航位置，页面运行内存随 guest 销毁。文件预览保留后来编辑的文件。
- 歧义点：无真决策（不持久化已由 ui-state-persistence 拍板节收录，其余边界是回放保护的一致性推论）。
