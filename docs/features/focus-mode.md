# 专注模式（GUI 会话 + Git 页双栏并肩满宽）

> 状态：实现说明 v1.5（2026-10-10：把手菜单「专注」落点改为「关闭虚拟屏」，入口只剩右栏开关展开恢复；拖拽加 lostpointercapture/blur 打断兜底）
> 代码主入口：`src/renderer/src/App.tsx`（状态/几何/把手）、`SplitExpandControl.tsx`（把手交互与长按菜单）
> 关联：横向虚拟屏见 `virtual-screen.md`（专注是它的临时替代态）；Git 页内容见 `builtin-browser.md` / `virtual-screen.md` §2.2；会话栏折叠/展开见 `sessions-dock.md`

## 1. 功能职责

专注模式把布局从「会话列表 + 中栏 + 虚拟屏切 Git」收敛为**两栏并肩恒满全宽**：

```text
普通：  [会话列表 | GUI 会话] ⇄(虚拟屏 peek/平移) [Git 页]
专注：  [        GUI 会话         ][     Git 页     ]   ← 之和恒为全宽
```

- 会话栏（若展开）与其拖宽手柄**保持原状、照常显示**（与专注解耦）；**工作区胶囊栈已并入左栏本体**（portal 进 `.left-ws-slot`，随侧边栏显隐），调度对话面板随「侧边栏隐藏 ⇔ 面板隐藏」的绑定联动（见 `sessions-dock.md` §6）；主区只剩会话（中栏 CenterPanel）和右侧 Git 页（SideToolsPanel：文件/Git/内置浏览器）。
- **虚拟屏逻辑整体退出**：无 peek、无平移、无悬停/点击切页热区；切页把手变成专注分割把手。
- 中间把手长按约 400ms 展开与虚拟屏共用的调节菜单。纵向拖到切屏方式后松手，会恢复虚拟屏并应用该方式。当前双栏模式在菜单中标记为「关闭虚拟屏」。Tab 到把手也可从键盘打开菜单。横拖调宽时，其他选项向中间收缩，加减号胶囊随两栏边界移动。
- **落点语义**：拖到「鼠标悬浮/点击切屏」= 一步**退出专注（恢复进专注前快照）+ 应用该切屏方式**，不必先退再切（`applySwitchModeFromMenu`）；「关闭虚拟屏」落点即本模式的进入口（原「专注」，2026-10-10 仅改名、行为不变），已在该态时空操作。
- 两侧宽度此消彼长，**之和始终是工作面宽度**（`focusRatio` 会话侧占比，钳制 0.25–0.75，默认 0.5）。专注态的两侧各露出 `--frame-gap` 框色留白（默认 4px），底部同样保留；中间两页各内收半个 token，合成等宽框背景间隔，并各自保留完整 `--radius-page`（10px）圆角。分割条仍位于原比例边界，静息透明，鼠标悬停和拖动时的 3px 线贯穿工作面高度。

## 2. 开关与作用范围

- 入口：**把手长按菜单「关闭虚拟屏」落点**（原「专注」，2026-10-10 仅改名——用户视角即「把虚拟屏关掉、两块面板全屏并肩」；拖选式：按住→拖到落点→松手提交）+ **右栏开关的「恢复专注」**（收起时是专注布局则记标记，展开恢复）。GUI 会话顶栏「专注」胶囊按钮已删（2026-09-09）。
- 菜单通常将点击、悬浮两项排在把手上方，「关闭虚拟屏」排在下方。靠近窗口顶底时，菜单移向有空间的一侧，可见的整行都能命中。从任意选项回到加减号所在行时，横向移动越过 8px 可转入调宽。调宽开始后持续到松手或取消。
- 专注是**全局布局态**：与当前激活会话无关（切到 CLI 终端会话保持专注）；**重启保持**（落 `workspace.json` 的 `focusMode`）。
- 窄屏（≤820px）不生效：布局归抽屉系统管（responsive.css），`is-focus` 类与把手语义都按 `focusMode && !narrow`（App 内 `focusLayout`）挂载，顶栏按钮在窄屏隐藏。
- **右上角右栏开关**：普通态开=拉起 VS 驻留 Git 页、关=VS 整体退出；**收起时把折叠前姿态（是否专注布局 + VS 驻留页 dock）存入 localStorage（`muster.rightPanelRestore.v1`，`rightPanelRestore.ts`），展开原样恢复——专注恢复专注，普通态回到收起时驻留的页**（2026-10-10：此前展开恒 `enableHVs('git')`，折叠前驻留会话页会被强切 Git、dock 无记忆）。收起动作本身=退专注+关 VS，走 `collapseRightPanel` 单条补丁原子落盘——此前 `exitFocus`+`disableHVs` 叠两条补丁，中间 cfg「focusMode 已 false 而 hVirtualScreen 还是盘上旧值」会被 hVs 同步 effect 复活成悬浮/点击虚拟屏（2026-09-09 修复；`exitFocus` 同步合并为单条补丁）。

## 3. 进入/退出与状态恢复（关键设计）

- **进入**：把当前 `{hVs, hDock, termRatio, gitRatio}` 存进 `focusRestoreRef`（内存级，**不落盘**），然后仅视觉退出虚拟屏（`setHVs(false)` 但**不写** `hVirtualScreen` / `hDock`）；`focusMode: true` 落盘。
- **退出**：恢复快照和本机页位，一次工作区配置补丁保存 `focusMode: false`、`hVirtualScreen` 和两页占比。
- **重启后退出专注**：从 `workspace.json` 恢复布局，从本机工作区键恢复进入专注前的页位。
- **跨工作区切换**时清除 `focusRestoreRef`。新区读取自己的工作区布局和本机页位，此时退出专注只保存 `focusMode: false`。
- cfg 同步 effect 按 `cfg.focusMode` 强制 `hVs=false`，防止「切回 focusMode=true 的工作区时把盘上 hVirtualScreen=true 一并拉起」的半破损态。

## 4. 几何与联动

- `focusLayout` 时：`workspacePageW = viewW × focusRatio`、`gitPageW = viewW − workspacePageW`、`hOffset = 0`（无平移）；`terminalInnerW = workspacePageW −（会话栏展开 ? leftW : 0）`——会话栏展开时专注分屏让出左栏宽（布局为 [会话栏 | 会话 | Git]）。
- ~~会话列隐藏~~（已废除）：专注**不再**对 `.sessions-column / .left-col-resizer` 做 display 硬切——会话栏显隐完全由左上角 logo 开关/热区速览控制（`sessions-dock.md`）；`.agent-float` 的显隐也改由绑定推导（`sessions-hidden` 类）。
- 把手拖拽复用 VS 的 `onResizeStart/Move/End` 状态机（`focusMode` 分支）：**不截图不铺快照、不渲染指示卡**（拖动=最普通窗口 resize，两侧直接活重排，2026-10-10 用户定稿）、松手落 `focusRatio`（阈值 0.002，Escape/取消回滚）。
- 内置浏览器已 `<webview>` 化、参与渲染层 DOM 合成（2026-10-08），拖动重排按普通 DOM 处理——旧的主进程让位体系（`yieldBrowserView`）已整体移除。
- `gitEverActive` 在专注下即置真：SideToolsPanel 的 Files/Git 内容懒挂载在专注首进时完成。
- **右区恒为激活态**（`SideToolsPanel` 的 `active` 并入 `focusMode`）：Git 页的 `fs:changed` 自动刷新与 `sideTools.*` 快捷键保持工作，内置浏览器可正常点击交互（2026-09-08 评审修复：此前 `active` 恒 false 导致右区不激活；2026-10-08 webview 化后浏览器本就参与渲染层 DOM，无指针管道一说）。
- `sideDockRequest`（程序化 dock 请求）在专注下只响应 dock 语义，不再拉起虚拟屏；
  `virtualScreen.toggle`（ctrl+shift+\）在专注期间不响应（避免改写 `hVirtualScreen` 破坏
  §5 的不变量），用把手菜单中的悬浮或点击切屏退出专注。
- **与侧边栏显隐完全解耦（2026-09-09 用户定稿）**：专注只改主区几何，**不触碰会话栏显隐**——会话栏展开/折叠由左上角 logo 开关（悬停变面板箭头；或折叠态左缘热区速览）控制，专注中照常可开合（展开时布局为 [会话栏 | 会话 | Git]）；调度对话面板随侧边栏显隐绑定（工作区栈随左栏本体，见 `sessions-dock.md` §6）。

## 5. 持久化字段（workspace.json）

| 字段 | 含义 |
|------|------|
| `focusMode` | 专注开关（重启保持） |
| `focusRatio` | 会话侧占比（把手拖动落盘） |

专注期间 `hVirtualScreen / hDock / hTerminalRatio / hGitRatio` 保持进入前的原值不动。左栏宽度是全局偏好，拖宽即时更新、松手保存；退出专注不恢复旧宽度。

## 6. 已知边界

- 窄屏使用抽屉布局并隐藏分割条和把手，拉回宽屏后恢复专注布局。
- 工作区切换的过场骨架对专注只做近似（藏会话列 + Git 侧用 peek 形态，胶片滑动 420ms + 骨架淡出 200ms 一闪而过）。
- 切到非 GUI 会话时专注保持（专注是全局布局态，不随会话切换）；会话栏折叠时切会话走全局看板，展开时照常点选。
- 右栏开关跨收起/展开保留的是「专注布局」本身：收起时专注快照按语义消费（落回普通全宽），展开恢复的专注以收起时的普通布局为快照——收起前若 VS 是开启态，展开→再退出专注后不会还原该 VS（需要时手动再开）。
- 专注下调度对话面板随**侧边栏显隐绑定**、工作区胶囊栈随左栏本体（见 `sessions-dock.md` §6）：会话栏折叠未速览时均不可见（含「需要你」通知气泡），此类提醒由全局看板探条独立承担；会话栏展开（含专注中展开）时随之出现。切会话仍可走全局看板。

## 设计初衷（2026-10-26 与用户定稿）

> 依据 campaign-intent-drafts/D07.md 草案定稿（用户 2026-10-26「不抽查直接定稿」）；歧义点处置：22 项卡片决策＋长尾按草案推荐，明细见专项账本「意图定稿决策」节。

- 为谁/什么场景：「关闭虚拟屏」=两栏并肩恒满全宽的布局替代态（会话+Git 并排）；与侧边栏显隐、会话切换完全解耦的全局布局态，重启保持。
- 为什么这样设计：进入专注保存内存快照，退出时按快照或当前工作区布局及本机页位恢复；拖动跟随窗口 resize；右栏开关记录折叠前姿态；退专注和关 VS 合并成一条工作区布局补丁。
- 明确不做：不藏会话栏（2026-09-09 定稿完全解耦）；窄屏不生效；Ctrl+Shift+\ 切页在专注期间不响应（保持久化字段不变量）；收起前若 VS 开启，展开→退专注后不还原该 VS（需手动再开）。
- 歧义点：无真决策（改名/无遮罩拖动/入口收敛均为 2026-10-10 用户定稿，快照恢复语义有明文与测试）。
